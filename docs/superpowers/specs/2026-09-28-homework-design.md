# 衡阳作业批改示范设计

用户已批准：湖南衡阳、小学三年级语文上册第一单元，同时支持在线答题和系统作业拍照批改。追加要求：树状结构支持扩展单元、学科。

目录节点使用稳定 ID、label、kind 和 children；作业叶子引用 worksheetId。层次为地区→年级→学科→教材册次→单元→作业。题库与 UI 分离。

React + TypeScript + Vite 静态前端发布 GitHub Pages。Node.js Express API 单独部署，使用环境变量配置 OpenAI 兼容视觉模型。不配置模型时明确降级为手动录入，不伪造识别或主观评分。

固定作业图片识别后必须允许用户校正。客观题规则评分，主观题使用题库采分点进行 AI 辅助评分并标记待复核；人工复核可以输入最终得分。暂不设置账号、云同步。浏览器保存答案、结果与错题，不持久保存照片。

图片限定 JPEG/PNG/WebP、单张 8MB；后端请求限流、超时、请求格式和模型输出校验。仅启用配置的前端 Origin。题库是原创示范，教材版本和课文对应关系需要使用者核对，不声称官方试题。

验收：树导航、在线提交、客观题判分、主观待复核、手动复核、错题重练、图片预览和确认、服务未配置提示、本地保存失败提示、打印、移动布局；测试评分/输出校验/API/浏览器流程，生产构建通过。
